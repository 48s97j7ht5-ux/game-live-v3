# PNG lab — эксперимент 01

Отдельная страница для подготовки прозрачных PNG и сравнения с исходником.
Редактор v5 не изменён. Обработка выполняется локально в Web Worker, без API,
учётной записи и отправки загруженных изображений на сервер.

## Алгоритмы

`engine.mjs` адаптирует идеи и части алгоритмов из
[Retro-Diffusion/pixel-art-fixer](https://github.com/Retro-Diffusion/pixel-art-fixer),
ревизия `ef376e57e1c272633ca2dbf5f29ec3fcf6596465`:

- Поиск расстояний между устойчивыми цветовыми границами и оценка их
  кратности предполагаемому шагу (`python/pixelfixer/runlengths.py`).
- Двухэтапный выбор: цветовая область, затем цвет внутри неё
  (`python/pixelfixer/reconstruct.py`, `two_stage_pack`).

Это уменьшенная браузерная адаптация, **не полный Retro Diffusion Standard**
и не его нейросетевая версия. Детектор не включает ансамбль FFT/автокорреляции,
медианный фильтр и интеграцию локального дрейфа. Его размер — предположение,
которое применяется только отдельной кнопкой. Пиксельную сетку размером 1 px
детектор не восстанавливает: готовый нативный спрайт следует оставить 1:1.

Изменения относительно оригинального восстановления:

- Полностью прозрачные пиксели исключены из палитры и цветовых голосов.
- Вес частично прозрачных пикселей зависит от alpha.
- Дробные границы ячеек учитываются по площади покрытия.
- Alpha результата бинарная; пользователь выбирает порог покрытия.
- Палитра строится детерминированно из взвешенной RGB-гистограммы.
- Финальные цвета привязаны к общей палитре, максимум 48 видимых цветов.
- Контрольное nearest-neighbor уменьшение использует ту же палитру и порог.
- Исходные байты не изменяются, после изменения настроек экспорт блокируется
  до пересчёта. Картинка не увеличивается при обработке.

Исходная лицензия MIT и авторство сохранены в `vendor/LICENSE.txt`.
Пример Кати предоставлен владельцем проекта; MIT upstream не распространяется
автоматически на изображения проекта.

## Ограничения

Пределы: исходник 4 млн пикселей, сторона до 4096 px; результат до 512×512.
Уменьшение неизбежно теряет детали: их может потерять и этот алгоритм.
Режим тонких краёв иногда возвращает нежелательные точки — проверяйте результат.
Размер PNG — размер холста, не высота тела. 208 px не означает автоматически
192 px от предполагаемой макушки до стоп. Подписи участков оптимизированы под
полнофигурную Катю; для других изображений используйте полный вид.

## Проверка

`tests/png-lab.cjs`: регрессия скрытого RGB, прозрачность, полупрозрачное
покрытие, неизменность исходника, точная сетка 4×, палитра, пределы и Катя.
`tests/png-lab-browser.cjs`: загрузка PNG, Worker, мобильная вёрстка, сравнение,
смена настроек, отмена и выгрузка настоящего PNG.
