# Носки / гольфы

Папка игровых элементов для слота `socks`.

- Раздел: Чулочно-носочное
- Системный слой: `socks_base`
- Базовый порядок отрисовки: `z = 510`
- Формат элемента: `.glitem`
- Размер рабочего холста: `135 × 400 px`

PNG хранится внутри контейнера `.glitem`, имеет прозрачный фон и сохраняет координаты общего холста персонажа.
