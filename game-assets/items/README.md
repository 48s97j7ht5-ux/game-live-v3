# Game Live items

Здесь хранится библиотека частей персонажа. Каждая подпапка соответствует значению `slot` внутри файла `.glitem`.

Редактор сохраняет элементы в путь `game-assets/items/<slot>/<id>.glitem`. Файлы других типов конструктор персонажа должен игнорировать.
